IoT Portfolio

ESP32 · Adafruit IO · MQTT · IFTTT · Firebase — five tasks, one rig.

These five pages document the IoT assignments from my ProtoSem 1.18 semester at Forge. They build on each other: one ESP32 starts by switching an LED from a browser and ends up as a logged, automated, cloud-connected light with a voice assistant and a web dashboard.

Task 1ESP32 Web Server & HTML LED ControlESP32 web server on the local network; an LED switched from a phone browser.Task 2Adafruit IO Dashboard & MQTTA mains bulb on a relay, switched from an Adafruit IO dashboard over MQTT.Task 3IFTTT + Adafruit IO Voice AutomationGoogle Assistant voice commands through IFTTT to the same Adafruit IO feed.Task 4Firebase IoT Monitoring DashboardDHT11 + LDR readings and bulb control on a Firebase dashboard with login.Task 5Firebase Logging, Automation & Data ExportTimestamped logging, automatic lighting from the LDR, a history chart and CSV export.
